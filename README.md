# 04b03 Cyrillic — Russian Pixel Font

**04b03 Cyrillic** is an unofficial Cyrillic extension of the 04b03 pixel font. It combines the original English/Latin characters with a complete Russian alphabet in one TTF file, including `Ё` and `ё`.

**04b03 Cyrillic** — неофициальная кириллическая версия пиксельного шрифта 04b03. Один TTF-файл содержит английскую латиницу и полный русский алфавит, включая `Ё` и `ё`.

![04b03 Cyrillic Russian and English pixel font preview](preview.png)

## Download / Скачать

- [04b03-Cyrillic.ttf](04b03-Cyrillic.ttf) — Russian Cyrillic + English Latin / русский + английский
- [04B_03.TTF](04B_03.TTF) — original 04b03 Latin font / оригинальный латинский шрифт

## Character support / Поддержка символов

- English uppercase and lowercase letters
- Russian uppercase and lowercase letters: `А–Я`, `а–я`, `Ё`, `ё`
- Numbers and the original 04b03 punctuation

## Installation / Установка

### macOS

Open the TTF file and select **Install Font**, or place it in `~/Library/Fonts`.

Откройте TTF-файл и нажмите **Установить шрифт** либо поместите его в `~/Library/Fonts`.

### Windows

Right-click the TTF file and select **Install**.

Нажмите правой кнопкой по TTF-файлу и выберите **Установить**.

### Web

```css
@font-face {
  font-family: "04b03 Cyrillic";
  src: url("04b03-Cyrillic.ttf") format("truetype");
  font-weight: normal;
  font-style: normal;
}
```
